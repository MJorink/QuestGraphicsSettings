# QuestGraphicsSettings
A BoneLab mod that brings some graphics settings to Quest Standalone. <br>

Last tested on:
- Lemonloader: 0.6.5.1
- BoneLab: Patch 6

## Current Features
- Render Scale
- Render Distance (Experimental)
- LOD Bias
- FFR
- Premade presets
- Custom presets
